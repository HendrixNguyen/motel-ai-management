## Failure and rollout gates

- 401 redirects to login via existing transports; 404 never reveals foreign motel/period; network/5xx remains generic. Invalid meter values never reach PUT. A period marked sent is read-only even if stale page still shows controls; backend remains final authority.
- Unknown `details.server`, malformed money, or mismatched API response fails closed; no silent last-write-wins. Preserve unsaved draft after failed save and expose retry with fresh timestamp.
- No DB migration. Ship only when docs describe live wire behavior, QR test scans expected payload, and fixture-backed mobile flow passes; defer contract/templates/OTP, renter portal, photo upload, Zalo delivery, and offline capture to their backend stages.
