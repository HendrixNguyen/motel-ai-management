# Nhà Số Gọn brand guidelines

## Identity

- Display name: **Nhà Số Gọn**
- Technical slug: `nha-so-gon`
- Voice: clear, calm, practical, respectful. Use Vietnamese sentence case and concrete actions.
- Tagline: `Quản lý nhà trọ gọn hơn mỗi ngày`. Use only on login and landing surfaces.

## Logo

Use geometric house mark with three signal bars. Pair mark with wordmark on desktop shell and login. Use mark alone for favicon, compact navigation, and app icons. Never use emoji, raster-only artwork, or gradients as required recognition.

## Colour

Use semantic app tokens from `frontend/src/app/globals.css`. Logo default is primary teal on light surfaces and white/primary-fixed on dark surfaces. Keep clear space equal to mark width on every side. Do not recolour mark per screen.

## Sizes and backgrounds

Validate SVG at 16px and 32px navigation sizes, 180px touch icon, and 512px install icon. Check primary-on-light and white-on-dark. Keep shapes legible without thin strokes below 1px at 16px.

## Accessibility

Wordmark is decorative when adjacent to an accessible page title; otherwise use `alt="Nhà Số Gọn"`. Favicon has no text requirement. Never communicate status through logo colour alone.
