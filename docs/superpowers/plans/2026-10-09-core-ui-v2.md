# Core UI v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Xây Core UI v2 ổn định, backward-compatible và được test đầy đủ trước khi triển khai các màn hình contract, CCCD, payment-proof, tickets, notifications và settings còn thiếu.

**Architecture:** Giữ component cũ hoạt động; bổ sung/chuẩn hóa primitive tại `frontend/src/components/ui/`, dùng semantic tokens chung cho manager và renter. Migrate từng caller sau khi primitive pass, không rewrite toàn app một lần.

**Tech Stack:** Next.js 16, React 19, TypeScript, Tailwind CSS v4, native dialog, Bun, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-09-core-ui-v2-design.md`, `docs/frontend-ui-specs.md`.

## Global Constraints

- Giữ backward compatibility cho Button, Field, Modal, Drawer, Badge, StatCard, EmptyState, DataTable, ToastProvider, useToast.
- Không thêm backend/API/business rules hoặc fake data.
- Minimum hit target `44x44px`; không overflow tại `360`, `375`, `430`, `1280`.
- Theme hỗ trợ `light`, `dark`, `system`; không dùng raw hex trong component.
- VND dùng digit-string safe; ngày hợp đồng giữ `YYYY-MM-DD` calendar semantics.
- Keyboard, focus-visible, focus restoration, aria-live, reduced motion bắt buộc.
- Dùng `bun`, `bunx`; không dùng `npm`, `npx`.

## Review Focus

- Component mới không phá prop contract cũ; test compatibility trong Task 1.
- Dialog/drawer không mất focus khi đóng hoặc Escape; test trong Task 3.
- Bảng mobile không che nhãn, action hoặc tạo horizontal scroll; test trong Task 4.
- File upload từ chối MIME/size sai và không lộ object key; test trong Task 5.
- Dark/system theme không flash, không mất contrast, giữ lựa chọn sau reload; test trong Task 2.
